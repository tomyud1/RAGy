# Auto-Update Hosting Guide

This guide explains where and how to host app updates for the auto-updater to work.

## How Auto-Updates Work

```
┌─────────────────────┐
│   User's App        │
│   (v0.1.0)          │
└──────────┬──────────┘
           │
           │ 1. Checks for update
           ▼
┌─────────────────────┐
│  GitHub Releases    │
│  or Update Server   │
└──────────┬──────────┘
           │
           │ 2. Returns: v0.2.0 available
           ▼
┌─────────────────────┐
│   User sees popup   │
│  "Update available" │
│  [Install Now]      │
└──────────┬──────────┘
           │
           │ 3. Downloads new version
           ▼
┌─────────────────────┐
│  Installs on quit   │
│  User restarts app  │
└─────────────────────┘
```

## Option 1: GitHub Releases (RECOMMENDED - Already Configured!)

Your app is already configured to use GitHub Releases. This is the easiest and most common approach.

### How It Works

`electron-updater` checks your GitHub repo's releases for new versions:
- Compares current version (0.1.0) with latest release version
- If newer version exists → notifies user
- Downloads installer from release assets
- Installs when user clicks "Install Now"

### Setup Steps

**1. Build Your App**
```bash
npm run electron:build:win  # or :mac, :linux
```

**2. Create GitHub Release**

Go to: https://github.com/tomyud1/RAGy/releases/new

- **Tag**: v0.2.0 (increment version number!)
- **Release title**: RAGy v0.2.0
- **Description**:
  ```
  ## What's New
  - Fixed crash on startup
  - Added Python bundling
  - Improved performance

  ## Installation
  Download the appropriate installer for your platform below.
  ```
- **Attach files**: Drag and drop the built installers
  - `RAGy-Setup-0.2.0.exe` (Windows)
  - `RAGy-0.2.0.dmg` (macOS)
  - `RAGy-0.2.0.AppImage` (Linux)
  - `latest.yml` (auto-generated, required for updates!)

**3. Publish Release**

Click "Publish release"

**4. App Auto-Update Works!**

When users with v0.1.0 start their app:
1. App checks GitHub releases
2. Sees v0.2.0 available
3. Shows update notification
4. User clicks "Install Now"
5. Downloads from GitHub
6. Installs and restarts

### Important Files

**latest.yml** (Windows) - Auto-generated by electron-builder
```yaml
version: 0.2.0
path: RAGy-Setup-0.2.0.exe
sha512: abc123...
releaseDate: '2024-11-25T10:00:00.000Z'
```

**latest-mac.yml** (macOS) - Similar format

These files tell the updater what version is available and where to download it.

**IMPORTANT:** Always upload these YAML files to your release!

### Configuration (Already Done)

In your `package.json`:
```json
{
  "build": {
    "publish": {
      "provider": "github",
      "owner": "tomyud1",
      "repo": "RAGy"
    }
  }
}
```

This tells electron-updater to check GitHub for updates.

## Option 2: Private Update Server (For Later)

If you don't want public releases or need more control:

### Simple Express Server

```javascript
// update-server.js
import express from 'express';
const app = express();

app.get('/update/latest', (req, res) => {
  res.json({
    version: '0.2.0',
    url: 'https://your-server.com/releases/RAGy-Setup-0.2.0.exe',
    releaseDate: '2024-11-25',
    releaseNotes: 'Bug fixes and improvements'
  });
});

app.listen(3000);
```

**Update package.json:**
```json
{
  "build": {
    "publish": {
      "provider": "generic",
      "url": "https://your-server.com/releases/"
    }
  }
}
```

**Pros:**
- Private updates (not publicly visible)
- Full control
- Can add authentication

**Cons:**
- Need to host/maintain server
- More complex
- Costs (server hosting)

## Option 3: Amazon S3 (Professional)

For production apps with many users:

```json
{
  "build": {
    "publish": {
      "provider": "s3",
      "bucket": "ragy-updates",
      "region": "us-east-1"
    }
  }
}
```

**Pros:**
- Scalable (handles thousands of downloads)
- Fast (CDN)
- Reliable

**Cons:**
- Costs money (~$1-5/month for small apps)
- Requires AWS account

**4. Test Update**
- Launch v0.1.0 app
- Wait 5 seconds (startup check)
- Should see "Update available" notification
- Click "Update Now"
- Should download and install v0.2.0

### Manual Update Check

Add a menu item or button:

**In your React app:**
```javascript
async function checkForUpdates() {
  if (window.electronAPI?.checkForUpdates) {
    const result = await window.electronAPI.checkForUpdates();

    if (result.available) {
      alert(`Update available: ${result.latestVersion}`);
    } else {
      alert('You are up to date!');
    }
  }
}

<button onClick={checkForUpdates}>Check for Updates</button>
```

## Troubleshooting

### Update Check Fails

**Problem:** App says "Error checking for updates"

**Solutions:**
- Check internet connection
- Verify GitHub repo is public
- Check `package.json` publish config is correct
- Check GitHub API rate limits

### Update Downloads But Won't Install

**Problem:** Update downloads 100% but nothing happens

**Solutions:**
- Close and relaunch app (installs on next launch)
- Check app has write permissions
- On Windows: Run as administrator if in Program Files

### "Update available" but same version

**Problem:** v0.2.0 app says update to v0.2.0 available

**Solutions:**
- Clear app cache: delete `AppData/Roaming/RAGy/` (Windows)
- Re-install app with new installer
- Check version in `package.json` matches release tag

## Best Practices

1. **Always increment version** before building
2. **Test on clean machine** before releasing
3. **Write clear release notes** so users know what changed
4. **Keep old releases** (don't delete) for rollback
5. **Test update flow** before announcing to users
